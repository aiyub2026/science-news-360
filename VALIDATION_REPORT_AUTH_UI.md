# Science News 360 V1.3.2 Authentication UI Validation

- Public readers can browse without registration.
- `Masuk` is intended for contributors, authors, reviewers, editors, publishers, and administrators.
- `Daftar Penulis` creates a Contributor account for drafting and editorial submission.
- `Kirim Artikel` redirects unauthenticated users to login and returns them to the content wizard.
- Submitted content cannot self-publish; publication remains controlled by editorial roles.
- Admin access remains separate and discreet.
