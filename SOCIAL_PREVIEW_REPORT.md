# SOCIAL PREVIEW REPORT — V2.0.12

Menu **Administrator → Pratinjau Berbagi** ditambahkan.

Fungsi:

- memilih artikel terbit;
- melihat alamat resmi;
- melihat URL gambar sosial;
- melihat nama situs dan jenis Twitter Card;
- melihat simulasi kartu WhatsApp, Facebook, X, dan LinkedIn;
- memperingatkan editor apabila gambar artikel masih berupa data lokal;
- menggunakan gambar cadangan bermerek bila URL HTTPS publik belum tersedia.

Ruang Editorial juga memiliki isian URL gambar sosial HTTPS dan alt text, beserta pratinjau langsung.
