# Social Share Test Checklist

- [ ] Netlify build succeeds.
- [ ] Final domain is set in `NEXT_PUBLIC_SITE_URL`.
- [ ] Publish an article from the editorial page.
- [ ] Reload the public article URL directly.
- [ ] Use View Source and confirm canonical, `og:*`, `twitter:*`, and JSON-LD are present in initial HTML.
- [ ] Open the `og:image` URL in a private browser window and confirm HTTP 200.
- [ ] Confirm the image is 1200 × 630.
- [ ] Confirm `/sitemap.xml` contains the article URL.
- [ ] Confirm `/rss.xml` contains the article URL.
- [ ] Test Facebook Sharing Debugger.
- [ ] Test LinkedIn Post Inspector.
- [ ] Send the canonical URL in WhatsApp.
- [ ] Test X and Telegram.
- [ ] Confirm thumbnail, title, description, site name, and link appear.
