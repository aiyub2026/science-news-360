# Changelog V1.3.7

## Inline Article Image Fix
- Corrected the stale-state upload bug that could retain only one of several selected images.
- Added a hard maximum of three inline article images per article.
- Added an immediate warning when the selected files exceed the remaining image allowance.
- Added a live upload counter (`0/3` through `3/3`).
- Added remove controls for each uploaded inline image.
- All uploaded inline images now appear in the article preview, in upload order.
- Existing draft/review, related-link, authentication, footer, author, and YouTube features are retained.
