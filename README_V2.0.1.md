# Science News 360 V2.0.1 — Author Experience Professional

## Run on Mac

```bash
npm install
npm run build
npm run dev
```

## Main routes

- `/dashboard/author`
- `/dashboard/author/create`
- `/dashboard/author/templates`
- `/dashboard/author/media`
- `/dashboard/author/profile`
- `/dashboard/author/content`

## Notes

This package implements the complete Stage-1 author experience in the current browser-persistence architecture. External AI, ORCID, Google Scholar, YouTube API synchronization, object storage, and database persistence require backend credentials and are therefore provided as safe integration frameworks rather than embedded secrets.
