# Daftar Periksa Sebelum Netlify

1. Jalankan `npm install`.
2. Jalankan `npm run build` dan pastikan tidak ada error.
3. Jalankan `npm run dev`.
4. Uji login Penulis dan Administrator.
5. Uji pembuatan, penyimpanan, pengiriman, peninjauan, persetujuan, dan penerbitan artikel.
6. Uji thumbnail dan maksimal tiga gambar isi.
7. Uji artikel terkait di tengah dan menjelang akhir artikel.
8. Uji pencarian, semua mega menu, footer, halaman kategori, video, penulis, dan materi kuliah.
9. Uji desktop, tablet, dan mobile.
10. Pastikan artikel terbit tampil di beranda, kategori, halaman penulis, dan dapat dibuka tanpa 404.
11. Pastikan data artikel tetap ada setelah browser dimuat ulang dan server dijalankan kembali.
12. Setelah seluruh pemeriksaan lulus, buat paket Netlify final.
